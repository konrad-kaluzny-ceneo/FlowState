# S-62: Agent Skill — FlowState sync + IDLE wait metrics

- **Outcome:** user can download a minimal Cursor/Claude **Skill** that, with minimal tokens, updates FlowState during AI-agent work (at least: start work on a task; finish work on a task; signal waiting for human); FlowState records agent **IDLE** wait time (agent blocked on human response) and presents it so the user can judge how many agents to run in parallel without stalling on their replies; notifications for those events are **deep-work aware** — e.g. suppress or defer when the user is in a deep-focus WORK cycle, surface calmly when interruptible.
- **Change ID:** `agent-idle-skill-wait-metrics`
- **Linear:** [FLO-106](https://linear.app/flowstate-10xdev/issue/FLO-106)
- **GitHub:** [#228](https://github.com/konrad-kaluzny-ceneo/FlowState/issues/228)
- **PRD refs:** proposed-FR-agent-idle-skill; extends S-46 MCP carve-out; attention carve-out family (break-alerts / S-60) — **not** a notification hub for external tools
- **Prerequisites:** S-46, S-31, S-37
- **Parallel with:** S-60, S-47
- **Blockers:** —
- **Unknowns:**
  - Skill delivery: in-repo `.cursor/skills` / downloadable gist / Settings link — owner: implementer. Block: no.
  - Event schema: start/end only vs also `waiting_for_human` / `resumed` — owner: user. Block: no (MVP: start, end, waiting).
  - Where to present IDLE wait + parallel-capacity hint: Podsumowanie vs Fokus rail vs Settings — owner: user. Block: no.
  - Deep-work gate: any WORK cycle vs only DEEP_WORK / focus-shell active — owner: user. Block: no.
  - Guest vs auth: MCP + skill auth-only? — owner: implementer. Block: no (default auth).
- **Risk:** medium — must stay token-cheap (Skill + thin MCP calls); easy to creep into full agent orchestration dashboard or notification hub (Non-Goal); deep-work suppression must not silently drop wait signals forever (queue/defer).
- **Status:** ready

## Scope notes (MVP)

1. **Skill (min tokens):** instruct agent to call existing/extended MCP with tiny payloads: `task_started`, `task_finished`, `waiting_for_human` (optional `resumed`).
2. **Metrics:** accumulate IDLE wait intervals per day/session; surface calm summary for parallel-capacity judgment (not streak/guilt).
3. **Notifications:** on `waiting_for_human` — if user in deep focus, defer; else calm browser/in-tab cue (reuse S-37/S-60 patterns; ≤1 concurrent nag style).

## Explicit non-goals for this slice

- No auto-starting Pomodoro when agent starts a task.
- No aggregating Slack/email/agent vendor push feeds.
- No multi-user team agent fleet UI.
